# Sample data

One real run from Google's Sycamore processor, so the quickstart works without a download:
distance-5 surface code, Z basis, 9 rounds, 50,000 shots.

Source: Google Quantum AI, Data for "Suppressing quantum errors by scaling a surface code
logical qubit", Zenodo, 2022. https://doi.org/10.5281/zenodo.6804040

Licensed under Creative Commons Attribution 4.0 (CC BY 4.0). The files are unmodified.
Only the five files the quickstart needs are included. `scripts/download_data.py` fetches
the full dataset (130 runs).
